# Nuvem Rush UI Refresh

Este projeto serve somente para criar a nova interface visual do aplicativo Nuvem Rush.

Não criar landing page.

Não implementar backend.

Não configurar Firebase.

Não criar autenticação.

Não criar APIs.

Não alterar integrações da Meta ou Nuvemshop.

Crie apenas as telas e componentes da interface do dashboard.

This project was built with [Lovable](https://lovable.dev).
